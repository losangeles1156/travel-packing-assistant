# 資料流程與已知界線

## 舊版清單

本機 `tpa_list_v1_*`、索引、目前清單及旅程摘要可下載成舊版 JSON；備份含私人資料，未加密。啟動時若尚未記錄遷移且有舊清單，先要求下載備份與使用者確認。缺少參考地區或方向時，必須由使用者逐筆選擇；已有值不覆寫。複製經驗證的清單與遷移標記在同一 IndexedDB 交易內完成；已存在 ID 跳過，舊 localStorage 保留。若舊資料格式無法驗證，停止遷移並提示保留備份。未支援的舊格式需個別處理，不能用預設值猜測。

## 現有行李頁

完成遷移後，清單建立、讀取和變更經 `ListRepository` 寫入 IndexedDB `lists`；目前清單 ID 與部分偏好仍在 localStorage。儲存為非同步且有短暫延遲；頁面關閉提醒與背景儲存無法保證所有瀏覽器或突然斷電皆可完成。切換頁籤、備份與匯入前要求先完成待存操作。以 Web Locks 限制同源單一寫入分頁；不支援該能力的瀏覽器目前無法開啟，跨瀏覽器／不同來源資料仍不共享。舊版資料仍保留，刪除新版資料不等於刪除舊版資料；已提供單筆清單與全部本機資料刪除介面；全刪除也清除本產品 tpa_ 偏好及 sessionStorage；新版與舊版儲存在不同系統，無跨系統交易，舊版清理失敗會明示部分失敗。

## 匯出、匯入

新版 JSON 為 v6，包含清單、行李單位與實測重量、航班與住宿、變動紀錄、交通安排及通訊與保險資料；目前尚無真實 AI 金鑰功能。新版可讀舊 v1 至 v5；舊程式與未支援未來版本應拒絕不認識的格式。讀取後先驗證與顯示數量及 ID 衝突，再選擇合併或取代；兩者均為單一資料庫交易。合併會覆寫相同 ID，取代會刪除新版資料庫中所有清單。不同瀏覽器、裝置及網址之間不會自動同步。備份未加密。

航班變動保存使用者確認時的原始航班快照、新出發時間、來源及記錄時間，不覆寫航班。交通安排可手動關聯航班；變動卡會顯示關聯交通與聯絡方式，但不推算交通是否受影響。航班被刪除時保留歷史快照；交通關聯顯示待重新確認。

通訊與保險資料由使用者確認後存入 `travelProtection`，不會與六項檢查的輸入自動同步。方案到期與選定事件的新出發時間均有日期、時間、時區時才比較；取消、缺資料、夏令時間不存在或重複時顯示未知。比較不等同確認抵達時間、實際網路可用或保障適用。

航班與住宿可手動輸入，或從明確的「中文欄位：內容」文字擷取草稿；原文不存入資料庫，確認前不寫入旅程。資料由使用者確認，不代表即時航班或訂房狀態。變更相關資料會將既有守護項目標示待複核，保留原有紀錄。

## 遠端

預覽版不自動送分析事件，分享與協作暫停；此修改不能關閉既有部署或改變遠端資料權限。外部樣式與字型已改為本機建置，先前版本已通過單一瀏覽器 PWA 離線重開與更新測試，跨裝置及更新中斷仍待驗證。旅程守護六項檢查目前接入手動記錄，資料併入清單及備份；來源、排程與完整驗收仍未完成。

檢查卡草稿存入清單的 guardian.drafts，經使用者記錄後才寫入 inputs；備份包含兩者。暫緩期限存於任務，日曆匯出在期限到期後顯示待辦；對既有無期限暫緩不推測日期。

使用者明確按重新檢視時，`guardian.runs` 記錄該項已確認輸入、基本判斷結果、規則版本及來源識別碼；每項最多 20 筆，會寫入 IndexedDB 與未加密備份。重開清單時若最近一次紀錄的規則版本或來源識別碼不同，保留紀錄並標示任務待複核；不會自動比對官方網頁內容。舊資料可沒有 runs。

出發與回程時區分別存於清單，均由使用者填寫，不依裝置時區猜測；匯出時可明確填寫或使用已保存值。日曆先預覽清單與時區，確認前若目前旅程或資料版本改變則需重做預覽。選配 AI 目前只有不連網的 fixture 模擬；驗證草稿原文位置後，只有經選取的欄位才可寫入，現有確認資料需單獨同意覆寫。實際供應商、gateway 與任何金鑰路徑均未啟用。

G1／G5 的靜態官方參考入口列於 `domain/sources.ts`，所記日期只代表查閱入口，內部複核日僅用於提示需要再次查閱；不會把任何旅客的資格或物品判為合規。連結本身可能需要網路，其他國家須查當地主管機關。
