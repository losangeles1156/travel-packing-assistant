# 前端操作檢查與修正紀錄

2026-11-08，以隔離瀏覽器和測試資料檢查，並非 Android 實機或無障礙認證。

1. **建立旅程**：手機首屏可看到目的地及日期，但需向下捲動才能看到建立按鈕。原本未輸入資料只出現籠統對話框；已改成欄位旁錯誤訊息與焦點提示，拒絕只有空白的目的地，建立中也防止重複提交。
2. **查看旅程**：旅程卡與分頁可辨識，但缺少時區時只顯示技術性提示。已增加直達設定的按鈕與常用時區選單；其他時區仍可自行輸入，不依目的地猜測。
3. **展開旅程檢查**：官方來源原本佔據大量篇幅，輸入欄位需要捲動很久。已將官方入口收在可展開區塊，保留「尚未核實」說明與來源複核資訊。
4. **整理行李**：手機版已確認行李與旅程頁可切換，先前修正的固定完成按鈕位於底部導覽上方。建立前新增目前規則參考地區與方向提示；目前僅提供既有的五個參考地區，無法自動判定輸入地點是否相符。
5. **備份與提醒**：工具選單可開啟日曆及備份。已做部分瀏覽器流程檢查；真實使用者資料、完整匯入中斷矩陣及第三方日曆通知仍待驗證。

最新修正已在隔離瀏覽器驗證：空白目的地錯誤與焦點、時區選取與重開後保存、來源區塊展開、快速重複操作僅建立一趟測試旅程。型別、正式建置與 115 項單元／API 測試通過。配色對比、螢幕閱讀器與 Android 實機尚未完成系統性驗收。

後續驗證：使用獨立測試資料，在瀏覽器完成六項檢查資料輸入、重新整理後確認完成狀態和住宿聯絡方式、修改旅程日期後確認待複核；另檢查備份預覽後資料變動會阻止合併，重新選擇備份後可合併，以及跨日後提醒匯出要求重新預覽。這些不是完整的備份、離線或日曆實際通知驗收。

受限環境曾因系統 Mach port 權限無法啟動 Chromium；修正兩個時區選單的測試定位後，使用者於 2026-11-08 在 Mac 執行 `npm run build` 與 `E2E_PWA=1 npm run test:e2e`。依使用者提供的終端機截圖，正式建置成功，完整 Playwright 腳本 7／7 通過，包含離線案例。測試僅涵蓋腳本情境，不代表所有裝置與例外情況已驗收。
