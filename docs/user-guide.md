# 旅程守護使用說明（開發預覽）

這是本機開發預覽，資料只保存在目前瀏覽器與網址，不會自動同步到其他裝置。首次載入需要連線；成功載入後可在支援的瀏覽器離線使用已保存的內容。清除瀏覽器資料、換網址或換裝置前，先下載備份。

## 建立旅程與檢查

輸入目的地與日期，確認參考地區及方向後選擇「建立行李清單」。若清單沒有你的目的地，請另查官方規定。建立後可在「旅程準備」和「行李清單」之間切換。在「旅程準備」展開六個項目並填寫資料；輸入先儲存成草稿，按「記錄這些資料」後才作為已記錄輸入。選擇處理狀態時，「完成」只是自己的紀錄，不表示航空公司或主管機關已確認合規；不確定的內容請展開「查看官方參考入口」自行查詢。選擇「切換／新增旅程」可回到已儲存旅程清單或建立新旅程。

出發與機場交通可選填住宿聯絡方式、最晚入住時間及中斷備忘。時間與時區請自行核對；系統不會替你聯絡住宿或判定是否可入住。頁面顯示「已儲存至本機」後再關閉或重新載入；若顯示儲存失敗，保留頁面並先排除問題。突然斷電或瀏覽器強制關閉不保證所有操作均已寫入。

已記錄的檢查若修改輸入草稿，會標示待複核；先按「記錄這些資料」，再按「記錄備註與重新檢視」。系統會保存當時的輸入及基本檢查結果，每項保留最近 20 筆，可在該項展開查看。這些紀錄留在本機，也會包含在未加密備份中；它們不是官方資格認定。規則版本或參考入口識別碼變更時，重新開啟資料會標示待複核。

總覽的「需要留意」包含尚未處理、待複核，以及雖標記完成但必要資料或適用性仍不明的項目。通訊檢查選擇「待確認」不會被當成裝置已支援或不支援；這些項目仍會留在提醒規劃中。

## 改期、取消與日曆

展開「變更旅程日期與時區」，填入日期及出發地、回程地時區，按更新。可以直接從常用時區選單選擇；其他時區可展開「自行輸入其他時區」填入 IANA 代碼。相關檢查會標記待複核；清單不會因此自動調整。取消旅程不會刪除紀錄，恢復後需重新檢視。

點擊右上角「工具」後開啟「匯出日曆提醒」，確認兩地時區、預覽內容後下載並自行匯入日曆。這是匯出時的快照，改期不會同步更新既有提醒；外部日曆可能產生重複項目，也無法保證通知會送達。

## 航班與住宿

在旅程中選擇「新增航班」或「新增住宿」，可記錄多筆資料。可貼上使用明確中文欄位名稱的訂單文字擷取草稿，再逐欄核對並確認；目前不支援 PDF、照片或各業者任意格式的自動辨識。原文不會保存，請勿貼上護照、付款資料或密碼。時間和時區不確定時可留空，記錄不會自動更新航班或訂房狀態。

## 航班變動與交通安排

新增航班後，可在「旅程變動」記錄延誤、取消或改期，輸入已確認的來源與新出發時間；系統會保留當時航班的快照，不會自動修改原航班。新時間不確定時可留空。機場交通可手動記錄鐵路、巴士、預約接送、計程車或其他安排，並選擇關聯航班；變動卡會提示關聯的交通及聯絡方式供自行確認。資料不是即時狀態，也不代表相關服務一定受影響。

## 通訊與保險守護

可記錄裝置相容性、上網方式與需求、供應地區、流量、啟用方式、已確認到期時間、客服和備援；保險可記錄保險公司、日期、聯絡方式、條款重點與事故處理。選擇已記錄的航班變動，可比較完整、已確認的方案到期與新出發時間；取消、缺少資訊或時區存在夏令時間歧義時不推測。資料與六項檢查分開記錄，不代表保證供網或保險理賠。當前沒有商品目錄或方案推薦。

## 備份、還原與刪除

點擊右上角「工具」，在「本機資料備份與還原」下載 JSON。備份包含私人行程及草稿，**沒有加密**，請妥善保管。選擇備份檔後會顯示數量及衝突：合併會以備份覆寫同識別碼清單；取代會移除目前清單再匯入。先確認預覽，必要時先備份目前資料。若預覽後又修改了本機清單，請重新選擇備份並確認預覽。刪除單趟或所有本機資料前請先備份，刪除已下載的備份檔需自行處理。

如果發現舊版清單，依畫面先下載舊資料備份並確認保存，再執行遷移；舊資料會保留。舊清單或舊備份缺少參考地區、方向時，先逐筆選擇適用於旅程的參考值，再遷移或預覽匯入；若沒有合適選項，請保留原始備份，暫勿猜測。瀏覽器可申請持續儲存，但仍建議定期備份。

## 目前限制

資料來源與個人適用規定尚未逐項人工核實，不提供即時交通與保證出發時間。選配 AI 尚未接上真實服務，無須提供金鑰即可使用核心流程。手機實機、外部日曆通知與正式部署尚待驗收。
