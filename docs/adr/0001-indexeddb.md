# ADR 0001：IndexedDB 清單儲存

狀態：已接入開發預覽，尚未完成全部驗收。採用瀏覽器原生 IndexedDB API 作薄型 repository，避免引入額外依賴。替代方案為 idb；若後續交易與 schema 維護成本超出可接受範圍，重新評估並鎖定版本。

清單資料庫版本 2 新增遷移標記；版本 3 引入守護卡草稿，版本 4 加入暫緩期限，版本 5 加入獨立適用性，版本 6 加入旅程取消狀態，版本 7 加入出發及回程時區，版本 8 加入航班與住宿記錄，版本 9 加入航班變動與交通安排，版本 10 加入通訊與保險資料，版本 11 加入物品單位及行李重量記錄；較舊程式不能以低版本寫入新版資料；舊程式若以較低 schema 開啟會收到 VersionError，不能寫入。匯入驗證後在單一交易完成。舊資料在使用者確認備份後複製、不刪除；重跑不覆寫已存在 ID。資料寫入按程序排隊；多分頁以 Web Locks 控制單一寫入。未通過完整的中斷、額度與版本升降測試，不得宣稱發布就緒。
